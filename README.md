
# Fanar Coffee ☕

An interactive web application designed for coffee ordering, featuring real-time data processing, dynamic price calculations, and automated billing workflows with a modern and responsive user interface.

## Features

* **Interactive Product Catalog:** Allows users to browse items seamlessly with a responsive layout.
* **Dynamic Price Calculations:** Utilizes robust JavaScript business logic to instantly calculate totals, manage quantities, and update prices in real time.
* **Automated Billing Workflow:** Generates a clear and summarized breakdown of the final order.
* **Responsive UI/UX:** Built using modern web design principles to ensure a smooth user experience across different devices.

 Technologies Used

* HTML5, CSS3, JavaScript
* Responsive Web Design Principles

## Getting Started

To run this project locally, simply clone the repository and open the index file in your preferred web browser.
